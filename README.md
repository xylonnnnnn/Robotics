# Робототехника — практические работы ROS 2

Личный репозиторий для ПР01 и ПР02 по робототехнике НГУ. Каждая работа находится в своей папке: [ПР01](PR01/) и [ПР02](PR02/).

Для сдачи нужен полный SHA коммита с `evidence`, а также ссылка на успешный запуск [GitHub Actions](.github/workflows/ci.yml) именно для этого SHA. В `report.json` каждой работы указан предшествующий коммит реализации.

Проверка воспроизводится из чистого checkout. Workflow скачивает закреплённую ревизию course kit `v1-w02`, сверяет SHA-256 архива, проверяет отчёты ПР01 и ПР02, а для ПР02 собирает `turtle_bringup` и проверяет установленный launch-файл.
