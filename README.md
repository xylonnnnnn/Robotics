# Робототехника — практические работы ROS 2

Личный репозиторий для ПР01–ПР03 по робототехнике НГУ. Каждая работа находится в своей папке: [ПР01](PR01/), [ПР02](PR02/) и [ПР03](PRO3/). Имя папки третьей работы — `PRO3`, номер работы в отчёте и checker — `PR03`.

Для сдачи нужен полный SHA коммита с `evidence`, а также ссылка на успешный запуск [GitHub Actions](.github/workflows/ci.yml) именно для этого SHA. В `report.json` каждой работы указан предшествующий коммит реализации.

Проверка воспроизводится из чистого checkout. Workflow скачивает закреплённую ревизию course kit `v1-w02` для ПР01–ПР02 и `v1-w05` для ПР03, сверяет SHA-256 архивов, проверяет отчёты, собирает ROS 2 пакеты и выполняет тесты ПР03.
